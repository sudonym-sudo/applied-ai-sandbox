# M6 — Other Tools Tour

## Copilot — installed/demo'd
- Observation: good for fast autocomplete as you type, but completely blind to project rules or CLAUDE.md.

## Cursor (or Windsurf) — installed/demo'd
- Observation: Composer makes multi-file edits easy since you see the diffs inline.

## Gemini CLI (or Codex CLI) — installed/demo'd
- Same prompt comparison: fast for quick codebase summaries, but doesn't feel as aggressive with terminal execution as Claude Code.

## Chat (Claude.ai or ChatGPT) — used for
- Observation: best for broad planning and pasting raw git diffs to get a high-level review without messing up local files.

## Tool decision matrix
| Situation | Tool I'd reach for | Why |
| --- | --- | --- |
| Multi-file feature with good CLAUDE.md | Claude Code | actually follows workspace rules and runs terminal commands |
| 5-line helper autocomplete while typing | Copilot | fast inline autocomplete keeps you in the flow |
| Brainstorm three design approaches | Chat | zero friction, can talk through ideas without messing with files |
| Review a teammate's PR for security issues | Chat | throw a raw git diff at it for a quick sanity check |
| Cross-file refactor with consistent renames | Cursor | Composer lets you review multi-file diffs side-by-side in the IDE |
| Learning a new library's API | Chat | solid conversational breakdown and clean sandbox code snippets |
